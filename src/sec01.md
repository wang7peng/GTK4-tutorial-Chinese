# 1 先决条件和许可

## 先决条件

### GTK 第4版 和 Linux操作系统

这是介绍 GTK4 **库** 的教程。Gtk 最初用于 Linux 上的图形化界面开发，使用 C 编译器编译。但是现在其用途更为广泛，在 Windows、MacOS 上也可以使用，还可以结合 Vala、Python、Ruby 等编程语言。不过，本教程只介绍*使用C语言在Linux上开发*。

如果你想尝试运行教程里的程序示例，需要:

- 安装了 Linux 发行版的电脑，比如安装了 `Ubuntu` 或 `Debian`
- GCC
- GTK 4 (4.10.1以上版本)

目前(2025年11月)最新的稳定版是 `v4.20.2`。新版本肯定调整了一些类和方法，增加了或者废弃了一些，所以教程里的一些示例程序在老版本环境下跑不起来。


### 使用 Ruby 和 rake 创建文档

英文版仓库自带了一些Ruby程序，可以使用那些程序创建 GFM（github定制版的Markdown文件）、HTML、Latex 以及 PDF 文件。

你需要运行它的环境：
- Linux
- Ruby语言环境。有两个方法搭建它，具体略。如果你想用最新版的 ruby，推荐使用 `rbenv` 工具。
- Rake
